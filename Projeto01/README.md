# 💻 Projeto01 - Primeiros Programas em Java

Este projeto foi desenvolvido durante meus estudos no curso de **Java** do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O objetivo das atividades foi praticar os **primeiros conceitos da linguagem Java**, criando pequenos programas para entender melhor a estrutura da linguagem e o funcionamento de aplicações simples.

---

# Objetivo do projeto

Este projeto foi criado para:

- Praticar os **fundamentos da linguagem Java**
- Entender a estrutura de um programa Java
- Trabalhar com **entrada e saída de dados**
- Desenvolver lógica de programação
- Organizar código utilizando **pacotes e classes**

---

# O que foi praticado

Durante o desenvolvimento deste projeto foram praticados conceitos como:

- Estrutura básica de um programa Java
- Uso da classe `System.out`
- Execução de programas simples
- Organização do código em arquivos `.java`
- Primeiros passos na linguagem Java
