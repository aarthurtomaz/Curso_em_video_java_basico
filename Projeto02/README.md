# 💻 Projeto02 - Informações do Sistema em Java

Este projeto foi desenvolvido durante meus estudos de **Java** no curso do **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

O objetivo das atividades foi praticar conceitos básicos da linguagem Java, criando pequenos programas capazes de obter informações do próprio sistema, como **hora atual, idioma do sistema e resolução da tela**.

---

# 🎯 Objetivo do projeto

O objetivo deste projeto foi:

- Praticar programação em **Java**
- Aprender a acessar **informações do sistema**
- Trabalhar com **classes e bibliotecas da linguagem**
- Organizar código em **pacotes**
- Melhorar a lógica de programação

---

# 📚 Funcionalidades

O projeto possui três programas principais:

### 🕒 Hora do Sistema
Exibe a **hora atual do computador**.

### 🌎 Idioma do Sistema
Mostra o **idioma configurado no sistema operacional**.

### 🖥️ Resolução da Tela
Exibe a **resolução da tela do computador**.
